On-device storage

Records stay primarily on the device

ColorCard stores client records and selected photos in app-owned local storage. It has no ColorCard account or cloud-sync service.

The operating system may separately include app data in device backup or migration. Review the Privacy Policy for the full boundaries.

Photo access

Photos are optional

If photo access is denied, client cards, formulas, and text-only visits remain available.

ColorCard does not use the camera or microphone. It lets you select images from the system photo picker for before-and-after records.

Backup safety

Keep backups in a trusted location

A backup may include client records and photos. It is not encrypted by ColorCard.

ColorCard checks a backup before replacing current records. Keep a known-good backup until you have checked the restored data.

Restore and data loss

There is no server copy for Support to restore

  • Force-closing or restarting the phone should not remove saved records.
  • Unsaved client, formula, and visit drafts may be restored when the same form is reopened.
  • Archiving a client keeps the record and is not deletion.
  • Uninstalling ColorCard normally removes app-owned local data from that device.
  • Exported files and operating-system backups must be deleted separately from their storage location.
  • Support does not have a server copy of your ColorCard records.

Troubleshooting

Things to check

A client is missing from the list

Clear the search field and check the Active, Favorites, and Archived filters.

A photo cannot be added

Check ColorCard's Photos permission in iOS Settings. You can continue and save a text-only visit.

A backup import is rejected

Confirm the file is an unmodified ColorCard JSON backup from a compatible version. A failed import should leave the current records unchanged.

A backup was shared to the wrong destination

ColorCard cannot recall a file after the operating system sends it to a destination you chose. Delete it from that provider or contact the provider directly.

Can I use ColorCard on Android?

The current release target is iPhone. Android device testing and release are deferred, with no announced release date.

How do I restore Lifetime Unlock?

Open Settings → Lifetime Unlock → Restore Purchases in ColorCard. Use the same Apple Account that made the purchase. If you need help, select Purchase or restore in the form above. Do not include receipts or payment details.
